# Этап 22. Файлы и фото: в сделке и в переписке с пациентом

## Что появилось

**Вкладка «Файлы» в сделке** (слева, рядом с «Основное» и «Оплаты»):
- файлы перетаскиваются в рамку или выбираются кнопкой «Загрузить файл», можно несколько сразу;
- до 20 МБ: фото, PDF, документы (Word, Excel, PowerPoint, OpenDocument, RTF, TXT, CSV), аудио и видео; неподходящий файл отклоняется сразу, с понятной ошибкой;
- в списке — миниатюра фото (по клику открывается во весь экран), имя, размер, дата, кто загрузил, «Из переписки» для файлов чата;
- у каждого файла кнопка «Скачать», по имени файл открывается в новой вкладке;
- удалить файл могут владелец, руководитель и тот, кто его загрузил. Файлы из переписки не удаляются: они часть истории общения.

**Лента сделки:** загрузка на вкладке «Файлы» появляется в ленте событием «Файл загружен» с превью.

**Карточка пациента:** блок «Файлы» — файлы всех сделок пациента с названием сделки.

**Отправка файла в чат:** в режиме «Сообщение» появилась скрепка. Выбранный файл показывается над полем ввода (его можно убрать), текст становится необязательной подписью. Файл уходит пациенту:
- через Wazzup24 (WhatsApp, Instagram, Telegram) — ссылкой `contentUri`. Wazzup24 не принимает текст и файл в одном сообщении, поэтому подпись уходит вторым сообщением сразу после файла;
- через Telegram-бот клиники — `sendPhoto`, `sendDocument`, `sendVideo`, `sendAudio` или `sendVoice` с подписью. По ссылке Telegram принимает фото до 5 МБ, PDF, GIF, ZIP, MP4 и аудио; остальное (например, .docx или фото 5–10 МБ) функция загружает в Telegram сама. Подпись длиннее 1024 символов уходит отдельным сообщением.

Отправленный файл сохраняется в сообщении и попадает в список файлов сделки.

**Входящие фото и файлы** больше не выглядят ссылкой: в пузыре сообщения — миниатюра фото (открывается во весь экран), плеер для голосовых и аудио, плеер для видео, для остального — плашка с иконкой, именем, размером и кнопкой скачивания. Подпись пациента к фото показывается под ним, служебный текст «[Фото]» скрывается.

**Копия входящих файлов:** вебхуки сразу копируют файл пациента в хранилище CRM, поэтому он не пропадёт, когда ссылка мессенджера истечёт. Такой файл тоже появляется во вкладке «Файлы».

**Демо:** у нескольких сделок есть загруженные снимки (ОПТГ, фото до лечения), в нескольких диалогах пациент прислал фото или анализы, а клиника ответила планом лечения в PDF. Загрузка, отправка и удаление работают в демо — файлы хранятся в памяти браузера.

## Как устроено

- Миграция `20261016000000_attachments.sql` (схема `22_attachments.sql`):
  - таблица `deal_files(organization_id, id, deal_id, patient_id, path, name, size, mime, sales_id, created_at, message_id)`. Пациент берётся из сделки триггером, при переносе сделки к другому пациенту файлы переезжают вместе с ней. База проверяет размер (до 20 МБ) и то, что путь лежит в папке этой сделки;
  - колонки сообщений `attachment_path`, `attachment_name`, `attachment_mime`, `attachment_size` — файл сообщения в нашем хранилище. `content_uri` по-прежнему хранит ссылку мессенджера;
  - приватный бакет `deal-files`: лимит 20 МБ и список разрешённых типов на уровне Storage.
- **Пути:** `<organization_id>/deals/<deal_id>/<uuid>-<имя>`. Имя в пути — только латиница и цифры (Storage не принимает кириллицу), настоящее имя хранится в `deal_files.name`.
- **Права в Storage** (`storage.objects`, бакет `deal-files`):
  - читать и загружать можно только в папку сделки, которую сотрудник видит (действуют правила видимости сделок для администраторов);
  - удалять — владелец и руководитель, или тот, кто загрузил объект;
  - другая клиника не видит и не может записать ничего в чужую папку, даже подставив номер чужой сделки под свой префикс.
- **Права на `deal_files`:** читают все, кто видит сделку; добавить можно только от своего имени и без `message_id` (файлы чата пишут edge-функции); изменять нельзя; удалять — владелец, руководитель или автор, кроме файлов переписки.
- **Ссылки:** бакет приватный, интерфейс получает подписанные ссылки на час. Мессенджерам уходит подписанная ссылка на 7 дней.
- **Отправка:** браузер загружает файл в папку сделки (проверку делают политики Storage), затем вызывает `messenger_send` с `file: {path, name, mime, size}`. Функция проверяет, что путь — в папке именно этой сделки, тип и размер, подписывает ссылку и вызывает `sendDealMessage` из `_shared/dealMessage.ts`. Чистые построители запросов: `wazzupMessageBodies` (`_shared/messenger.ts`) и `telegramSendPlan` (`_shared/telegram.ts`), правила типов и путей — `_shared/attachments.ts` (двойник в приложении — `files/fileTypes.ts`).
- **Входящие:** `wazzup_webhook` и `telegram_webhook` после ответа мессенджеру (`EdgeRuntime.waitUntil`) скачивают файл (`contentUri` Wazzup24; у Telegram — `getFile` с токеном бота, токен в браузер не попадает), кладут его в папку сделки, заполняют `attachment_*` у сообщения и добавляют строку в `deal_files` (`_shared/incomingMedia.ts`). Файл больше 20 МБ или неподходящего типа остаётся ссылкой мессенджера.
- **Журнал действий:** загрузка и удаление файлов на вкладке «Файлы» записываются в журнал (объект «Файл», фильтр «Сделки»). Файлы переписки в журнал не пишутся.
- **Заметки** по-прежнему хранят вложения в публичном бакете `attachments` — там ничего не менялось.

## Известные ограничения

- **Без живых ключей Wazzup24 и Telegram не проверено:** реальная отправка файлов и копирование входящих. Мессенджер должен сам скачать файл по ссылке, поэтому Storage должен быть доступен из интернета (на локальном стенде — нет). e2e не отправляет файл в чат: без Wazzup24 это невозможно.
- **Подписанная ссылка живёт 7 дней:** если мессенджер (или получатель) откроет её позже — файл не скачается. Wazzup24 скачивает файл сразу при отправке.
- **Подпись в Wazzup24** приходит пациенту вторым сообщением.
- **Файлы из переписки не удаляются** из интерфейса. Удалённый файл вкладки «Файлы» исчезает и из хранилища; сообщения чата, удалённые вместе со сделкой, оставляют объекты в хранилище (как и раньше для вложений заметок).
- **Копия входящих** — «по возможности»: при ошибке скачивания остаётся ссылка мессенджера, повторной попытки нет. Файлы больше 20 МБ не копируются (у Telegram-бота `getFile` и так не отдаёт больше 20 МБ).
- **Превью** есть у фото; PDF и документы открываются в новой вкладке браузера. HEIC с iPhone многие браузеры не показывают — такой файл можно скачать.
